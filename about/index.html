About Loftia Tools

Loftia Tools is a small, independent fan project that makes calculators and planners for the cozy MMO Loftia. It is not affiliated with, endorsed by or connected to Qloud Games. We do not use official logos.

We list a number only when we can trace it to a source below. Unknown values are marked TBD, and you can enter your own. Found a mistake or a new Early Access number? Open an issue on GitHub.
